В функции hard::C:check:

Структура S проходит проверку => al = 1 => Access Granted!
Не проходит => al = 0 => Access Denied!

Для Access Granted!:

В EXC необходимо передавать такое число, у которого byte0 и byte2-3 не равны 0.
Последний бит в каждом из 8 байт структуры S не должен быть равен 0.


Что проверяется:

1. Младший байт адреса объекта c, и 2-ух байтовое значение начиная с 2 байта (2-3)

2. Берем младшие 32 бита из 1 поля объекта s, считается кол-во единиц на основе gray кода
   Берется первый байт объекта c, он должен быть не больше, чем вычисленное кол-во единиц

3. Берется 2 поле объекта s, берется экспонента
   Берем 2-ух байтовое зна адреса объекта c
   Экспоната из 2 поля объекта s должна быть не меньше, чем отрицание этого 2-ух
